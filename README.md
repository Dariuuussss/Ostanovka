# Остановка

Каркас одностраничного сайта проекта «Остановка» для предпросмотра.

- `index.html` — основная HTML-страница
- `css/reset.css` — сброс стандартных отступов и базовые правила
- `css/style.css` — будущие стили сайта
- `assets/images/` — изображения проекта
- `assets/fonts/` — шрифты проекта

На этапе предпросмотра основная вёрстка ещё не выполнена.
